Полнофункциональная классическая игра **Sudoku Pulse**, написанная на чистом **TypeScript** без тяжелых сторонних фреймворков и игровых движков. Разработана для демонстрации алгоритмов генерации/решения, ООП и современных веб-технологий (DOM API, Web Audio API, Canvas Confetti).

---

## 🚀 Возможности и механики

1. **4 уровня сложности и баланс подсказок**:
   - *Легкий*: ~40 открытых цифр, **5 подсказок**, 3 ошибки
   - *Средний*: ~32 открытых цифр, **3 подсказки**, 3 ошибки
   - *Сложный*: ~26 открытых цифр, **2 подсказки**, 3 ошибки
   - *Эксперт*: ~22 открытых цифр, **1 подсказка**, 3 ошибки
2. **Блокировка ячеек после верного ввода**:
   - При вводе правильной цифры ячейка навсегда фиксируется (`isLocked`), исключая случайное стирание или перезапись.
3. **Умная и аккуратная индикация ошибок**:
   - Сама ошибочная ячейка выделяется красным цветом, и покачивается **только цифра** внутри неё (сетка ячейки остаётся неподвижной).
   - Одинаковые цифры в строке, столбце или блоке $3 \times 3$, с которыми возник конфликт, **не красятся в красный**: они подсвечиваются мягким синим цветом и привлекают внимание плавной пульсацией.
4. **Сбалансированная система подсказок и монетизация**:
   - Подсказки ограничены на каждый уровень сложности.
   - Когда лимит исчерпан, кнопка предлагает получить дополнительную подсказку через **симуляцию просмотра спонсорской рекламы** (3-секундный таймер с прогресс-баром).
5. **Система жизней и Game Over**:
   - Лимит из 3 ошибок (`Ошибки: 0/3`).
   - При 3 ошибках открывается окно окончания игры с возможностью взять **«Второй шанс»** (+1 жизнь за просмотр симуляции рекламы) или начать заново.
6. **Аудио-сопровождение (Web Audio API)**:
   - Синтез звуков в реальном времени без внешних файлов: клик, верный ввод, ошибка, сборка линии и фанфары победы. Кнопка выключения звука 🔊/🔇 сохраняет выбор в `localStorage`.
7. **Анимация сборки рядов**:
   - При полном заполнении любой строки, столбца или квадрата $3 \times 3$ по ячейкам проходит световая волна.
8. **Режим заметок (Pencil Marks / Кандидаты)**:
   - Клавиша `N` или кнопка в панели. При вводе верной цифры заметки автоматически вычищаются из связанных ячеек.
9. **История ходов и горячие клавиши**:
   - `1 - 9`: ввод цифры или заметки.
   - `Стрелки`: навигация по полю.
   - `Delete / Backspace`: очистка (для незаблокированных ячеек).
   - `Ctrl + Z`: отмена хода.
   - `H`: подсказка.
   - `P` / `Escape`: пауза с сокрытием поля.
10. **Победный экран**:
    - Праздничный салют конфетти на HTML5 Canvas и карточка со статистикой.

## 📂 Структура проекта

```text
sudoku-ts/
├── index.html           # Разметка страницы, интерфейс и модальные окна
├── package.json         # Скрипты и зависимости (TypeScript, Vite)
├── tsconfig.json        # Конфигурация компилятора TypeScript (строгий режим)
├── vite.config.ts       # Относительные пути сборки для автономной работы
└── src/
    ├── types.ts         # Интерфейсы, типы данных и конфигурации сложности
    ├── audio.ts         # Звуковой движок на Web Audio API (без внешних mp3)
    ├── solver.ts        # Алгоритм проверки правил и Backtracking-решатель
    ├── generator.ts     # Генератор валидного поля с единственным решением
    ├── game.ts          # Игровая модель (State Management, Undo/Redo, жизни, подсказки)
    ├── ui.ts            # Отрисовка DOM, обработка событий, модалки, салют
    ├── style.css        # Современный адаптивный дизайн (CSS переменные, темы)
    └── main.ts          # Точка входа приложения
```

## ⚙️ Установка и запуск

### 1. Запуск в режиме разработки:
```bash
npm run dev
```
Откройте ссылку в браузере: `http://localhost:5173`.

### 2. Сборка проекта (Production):
```bash
npm run build
```
Собранные файлы находятся в `dist/` и могут открываться даже автономно без сервера.
